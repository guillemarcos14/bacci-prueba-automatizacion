Control de cargas

Historial para comprobar qué datos entraron, cuánto tardó el proceso y si el resultado cambió.

Esta pantalla permite saber si los correos de un lote entraron correctamente y si volver a procesarlo cambia la cola. Cada cifra corresponde a esa ejecución. El código de «Resultado» identifica la versión de la cola: si no cambia, la salida es idéntica. El botón lee Correos_actualizacion.xlsx y conserva los mensajes anteriores.

Nuevos
Identificadores de mensaje no vistos antes; se incorporan.
Repetidos
Mismo identificador y contenido; se ignoran para evitar duplicados.
Conflictos
Identificador reutilizado con otro contenido o registro sin ID o fecha válidos; requieren revisión en el archivo de origen.
