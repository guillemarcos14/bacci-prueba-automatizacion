# Priorización para operaciones

La prioridad es una regla visible, sin puntuación opaca. Dentro de «Alta» se ordena: cancelación, adelanto para el día del corte, contacto o remitente por verificar, datos de cantidades imposibles, compromiso vencido y compromiso para hoy. Los casos de correo sin correspondencia que solicitan cambios se sitúan junto a las verificaciones humanas.

«Media» reúne cambios de fecha futuros pendientes de viabilidad, datos incompletos, compromisos en los próximos dos días y consultas de estado. «Baja» reúne líneas pendientes sin otra señal. Dentro de un mismo grupo se usa la fecha comprometida más temprana y luego una clave estable.

Esta cola ayuda a escoger el siguiente trabajo; no afirma qué se puede enviar realmente. Un correo no desplaza la fecha del ERP. Un caso puede permanecer sin resolver si la evidencia no basta. El equipo decide y registra el resultado fuera de este prototipo.

La prioridad describe **casos activos**. Una línea con 0 pendientes y ninguna petición o anomalía queda «Servido» en Todos los registros, fuera de la cola. Al filtrar por prioridad desde Todos los registros, las líneas servidas se excluyen: «Servido» es un estado, no una variante de «Baja».
